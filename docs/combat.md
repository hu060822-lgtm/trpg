# 互動戰鬥（第一版）

這份文件記錄已經做出來的互動戰鬥：規則、流程、GM 工具和還沒做的部分。設計討論與替代方案見設計文件（claude.ai artifact「FATEWEAVE 互動戰鬥設計」）；這裡只寫程式實際的行為。

## 定案（luz，2026-10-29）

1. **所有互動都在擲骰之後。** 攻擊先擲命中骰，再做武器操作；命中後先擲傷害，再閃避。豁免型攻擊先擲傷害，目標擲完豁免後再閃避。
2. 一次做完所有功能，當作第一版改造版試玩。
3. 規則照 5E。
4. 閃避難度用模型 B（依差距分五個局勢）。

## 一次攻擊的順序

```
宣告（射程、視線、動作數都先檢查）
  → 攻擊擲骰（玩家按住搖骰、放開擲出；伺服器擲）
  → 武器操作（品質 0–1，換成 +0／+1／+2；自然 1 或 20 跳過）
  → 判定命中（總值 ≥ AC；自然 20 必中、自然 1 必失）
  → 傷害擲骰（重擊時傷害骰再擲一次）
  → 閃避（只有玩家控制的目標）
  → 套用傷害
```

豁免型攻擊（法術、龍息）：宣告 → 傷害擲一次 → 每個目標擲豁免（玩家自己擲、GM 的生物自動）→ 成功減半或無傷 → 玩家目標閃避 → 套用。

## 模型 B：閃避局勢

差距 m：攻擊型是 `AC − 攻擊總值`，豁免型是 `豁免總值 − DC`。m 越大越有利。重擊一律「危急」。

| 局勢 | m | 時間 | 彈幕量 | 線結速度 | 場地大小 |
|---|---|---|---|---|---|
| 壓制 | ≥ 5 | 3 秒 | ×0.6 | ×1.1 | ×1.2（全場） |
| 優勢 | ≥ 1 | 4 秒 | ×0.8 | ×1 | ×1 |
| 均勢 | ≥ −2 | 5 秒 | ×1 | ×1 | ×1 |
| 劣勢 | ≥ −6 | 5 秒 | ×1.25 | ×0.85 | ×0.9 |
| 危急 | 更低 | 6 秒 | ×1.5 | ×0.7 | ×0.75 |

一般敵人（minion）的攻擊最多只閃 3 秒。

**傷害倍率**：閃避中被打中 0 次 ×0.5、1 次 ×0.75、2 次 ×1、3 次 ×1.1、4 次以上 ×1.25。無條件捨去，有傷害時至少 1。

這些數字都在規則包的 `combat.json` 的 `rules` 裡，可以改。

## 武器操作

| 操作 | 武器 | 做法 |
|---|---|---|
| 斬擊 | 劍、斧、棍 | 一筆畫過弱點線，畫得準、時間在 150–700 毫秒之間最好 |
| 突刺 | 匕首、細劍、矛 | 按住，外圈縮到目標圈時放開 |
| 橫掃 | 長柄、重武器 | 沿弧線一口氣拖過 |
| 拉弓 | 弓、弩 | 按住拉滿，準心會晃，晃到中間放開 |
| 符文 | 戲法 | 照順序連起符文點 |

品質 ≥ 0.9 加 2，≥ 0.6 加 1。每種操作都有**單鍵模式**（空白鍵或點一下，看時機），在戰鬥設定打開。

## 閃避

- 線結在框裡，鍵盤用方向鍵或 WASD；手機是手指放在場內任何地方滑動，線結照手指移動的方向走，手指不會擋住線結。
- 瀏覽器和伺服器跑**同一份**模擬（整數運算、固定亂數種子、每秒 60 格）。玩家送出每一格的方向，伺服器重跑一次算被打中幾次，所以結果跟網路速度、畫面幀數無關，改網頁也作弊不了。
- 被打中後有 0.75 秒無敵；雷射先閃 0.6 秒警告；最後 1/3 秒不再發射新的彈。
- 按下「開始閃避」後就不能重來。斷線或時間到，照骰子傷害（×1）算。
- 別人閃避完，其他人會自動看到重播（戰鬥設定可以關），戰鬥紀錄裡每次閃避都有「重播」。

## 模式

- **完整互動**：玩家擲骰、做武器操作、閃避。
- **快速結算**：全部自動擲骰，照骰子結算。
- **GM 自訂**：每個參戰者個別設定「照重要度／完整／快速」。

玩家自己的設定：互動程度（完整、減量＝彈速 3/4、關閉＝全自動）、單鍵模式、高對比彈幕、自動看重播、略過動畫。

## 回合與移動

- 先攻：玩家按住搖骰；GM 的生物自動擲。順序照先攻、平手看敏捷。
- 戰鬥中拖曳代幣就是移動：只能在自己的回合、用剩下的移動距離，繞過牆和敵人，不能停在別人的格子上。走得到的格子會淡綠色標出來。GM 在暫停時可以自由擺放任何代幣。
- 動作：攻擊（戰士 5 級的額外攻擊、怪物的多重攻擊都算）、施放戲法、衝刺、閃避動作（攻擊你的人有劣勢）、結束回合。
- 優劣勢：中毒、目盲、束縛、恐懼、倒地、目標閃避動作、遠程攻擊時身邊有敵人、超過一般射程。
- 0 生命的角色在自己回合擲死亡豁免；倒地時被打中算失敗（重擊算兩次），一次傷害超過生命上限直接死亡。

## 法術

目前只支援**戲法**（不耗法術位）：火焰箭、冰凍射線、聖焰、惡言相加、酸液飛濺等 11 個，傷害隨等級成長。一環以上的法術還是用角色卡的擲骰按鈕，因為還沒有法術位追蹤。

## GM 工具

- **開始戰鬥**：勾選代幣、選怪物圖鑑或自填 AC／HP／命中／傷害、加遭遇範本、選模式、NPC 自動行動、公開敵人生命。另有長休（角色生命回滿）。
- **主控台**：暫停／繼續（倒數會停住）、跳下一位、取消攻擊、結束戰鬥、讓這步重來、跳過這步、指定結果（操作品質、被打中次數、攻擊總值）、改生命、狀態、先攻、現身、重要度、彈幕、互動設定、再給一個動作、加入或移出參戰者。每個調整都寫進紀錄，可以附理由。
- **觸發器**：生命低於幾 %、到第幾輪、走進區域 → 說一段話、現身、換彈幕、升為 Boss。
- **Boss 階段**：怪物的 `phases`，生命掉到門檻時換彈幕並說台詞（幼紅龍有兩個階段）。
- **彈幕編輯**：用發射器（扇形、環形、瞄準、雨、雷射、螺旋、牆）組彈幕，旁邊即時預覽，存在房間裡。
- **NPC 自動行動**：輪到 GM 的生物時等 3 秒，GM 沒接手就自動走向最近的敵人攻擊；範圍攻擊能打到兩個以上才用。

## 看得到什麼

- 玩家看不到隱藏的生物，也看不到敵人的確切生命和 AC（顯示「毫髮無傷／輕傷／重傷／奄奄一息／倒下」），除非 GM 打開公開敵人生命。
- 隱藏生物的動作只有 GM 看得到；它攻擊時會現身。

## 2.5D 斜視

地圖工具列的「俯視／2.5D」切換。斜視只是另一種畫法：位置、距離、視線都還是照方格算，兩種畫面不會不一致。牆和家具照高度立起來，代幣照高度浮起，可以左右轉 90 度。點代幣選取、再點地面移動。

代幣可以設高度（飛行、站在高台），距離會算進高度差。物件可以設高度、門窗可以打開（打開不擋視線和移動）。

## 平衡

`npm run sim:dodge` 用三種機器人跑每個彈幕與局勢，結果在 `reports/dodge-balance.md`。**機器人不是真人，這不是平衡證明。** 目前的數字顯示：完全不動的人平均吃 ×0.67（壓制）到 ×1.09（危急）；簡單的貪婪閃避機器人只吃 ×0.51–×0.68。也就是說會閃的玩家受到的傷害可能比原版 5E 少三到四成，遭遇會變簡單。要找真人試玩後再調 `factors`。

## 還沒做

- 一環以上的法術、法術位、專注、反應動作（藉機攻擊、護盾術）、借機攻擊。
- 掩蔽（半掩、四分之三掩）只用來擋視線，還沒加 AC。
- 彈幕沒有「一定有安全路線」的檢查，靠無敵時間和密度上限避免無解。
- 即時觀戰是在閃避結束後重播，不是同步直播。
- 怪物資料是 2014 SRD 風格的數值，名稱與數字以原文為準。
