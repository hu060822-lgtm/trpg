# FATEWEAVE 規則規格 v0.3

**狀態：** 正式遊戲使用的規則版本。數值尚未經過完整測試，**不代表判定、生命值或職業已經平衡**。
**對應設定檔：** `config/rules.v03.json`、`config/skills.json`、`config/classes.json`、`config/creation-examples.json`
**歷史版本：** `config/rules.v02.json` 只供模擬器比較，正式遊戲會拒絕載入（`getRules('0.2')` 會丟出錯誤）。

## 1. 十項屬性

STR 力量、AGI 敏捷、VIT 體魄、PRE 精準、PER 感知、INT 智識、WIL 意志、CHA 魅力、INS 直覺、SPR 靈性。屬性範圍 0–6。

## 2. 判定

### 2.1 公式

`總判定值 = D20 + 屬性 + 技能 + 修正值`

- D20：1–20。屬性：0–6。技能：0–7。
- 修正值＝情境修正＋裝備修正，**兩者相加後**再套用上限 ±5（見 2.7）。
- 不使用 D6 波動。
- 理論最大值：20 + 6 + 7 + 5 = 38。屬性加技能最高 13。

### 2.2 難度

| 難度 | TN | 成功率約 50% 的加值（屬性＋技能） |
|---|---:|---:|
| 簡單 | 11 | 0–1 |
| 普通 | 14 | 3–4 |
| 困難 | 17 | 6–7 |
| 極難 | 20 | 9–10 |
| 傳奇 | 23 | 12–13 |
| 神話 | 26 | 需要情境、優勢、合作或道具 |

技能範圍改為 0–7 後，階梯改成步距 3。神話難度刻意超過角色自身的能力上限：屬性與技能全滿（加值 13）的角色，一般擲骰 40%，加上優勢與情境 +3 後才超過一半。

### 2.3 結果分級

差距＝總判定值 − TN。

| 差距 | 結果 |
|---|---|
| +6 以上 | 卓越成功 |
| +3～+5 | 強成功 |
| 0～+2 | 普通成功 |
| −1～−3 | 部分成功 |
| −4～−7 | 失敗 |
| −8 以下 | 災難性失敗（受 2.4 限制） |

### 2.4 災難性失敗

- GM 必須在擲骰前把行動標記為「高風險」，並讓玩家知道有重大風險。
- 只有高風險行動，差距 −8 以下才算災難性失敗；未標記的行動一律算失敗。
- 自然 1 讓失敗降為災難的規則，不論是否標記都適用（每次擲骰最多 5%）。

### 2.5 自然 1 與自然 20

- 自然 20：原始結果至少為普通成功時，提升一級；已是卓越成功時，另外獲得一項額外優勢。
- 自然 1：原始結果低於普通成功時，降低一級；已是災難性失敗時，不再降級。
- 自然骰只改變結果等級，不改變成功或失敗。
- 設定檔開關：`check.naturalRules`（預設開啟）。
- 尚待確認的細節列在 `CONFLICTS.md`。

### 2.6 免擲骰與做不到

- 最低可能總值（1 + 屬性 + 技能 + 修正值）≥ TN：自動普通成功，不擲骰。
- 最高可能總值（20 + 屬性 + 技能 + 修正值）< TN：GM 必須告知玩家「以目前條件做不到」，並說明可以改變哪些條件。不得讓玩家擲必敗的骰。

### 2.7 優勢、劣勢與修正

- 優勢：擲兩次 D20 取高；劣勢：取低；兩者同時存在則抵銷；同類不累加。
- 換算參考：在成功率 50% 附近，優勢約等於 +4～5。
- 情境修正與裝備修正**合計**上限 ±5。不得分開各自套用上限後再相加。例如情境 +4、裝備 +3，合計 +7，只套用 +5。
- 新裝備或能力必須寫明它給的是優勢、劣勢還是固定修正。

### 2.8 技能 0

技能 0（未受訓練）不會自動禁止一般行動，角色仍可用屬性擲骰。只有規則明確寫出「最低技能等級」的行動，技能不足時才不能嘗試（引擎欄位 `minSkill`）。

## 3. 角色建立

### 3.1 屬性

- 15 點屬性點數，自由分配到十項屬性。
- 每項最低 0。
- 創角時不另設單項上限，但不能超過屬性範圍上限 6。
- 十項屬性總和必須恰好為 15。

範例（`config/creation-examples.json`，由測試驗證）：

| 屬性 | 戰士型 | 斥候型 | 學者型 |
|---|---:|---:|---:|
| STR | 3 | 1 | 0 |
| AGI | 2 | 3 | 1 |
| VIT | 3 | 1 | 1 |
| PRE | 1 | 2 | 1 |
| PER | 1 | 3 | 2 |
| INT | 0 | 1 | 4 |
| WIL | 2 | 1 | 2 |
| CHA | 0 | 0 | 1 |
| INS | 2 | 2 | 1 |
| SPR | 1 | 1 | 2 |
| **合計** | **15** | **15** | **15** |

### 3.2 技能

- 技能等級範圍 0–7。
- 技能點數 20 點。
- 創角時單項技能最高 3。
- 職業核心技能合計至少 4 點。

屬性可以在創角時堆到 6，所以開局本職加值最高 6 + 3 = 9，距離上限 13 還有 4 點成長空間。

### 3.3 生命值（原型暫定）

HP ＝ 10 ＋ 2 × VIT。待戰鬥測試驗證，不是最終數值。

## 4. 技能

### 4.1 等級稱號

| 等級 | 稱號 |
|---|---|
| 0 | 未受訓練 |
| 1 | 初學者 |
| 2–3 | 熟練者 |
| 4–5 | 專家 |
| 6 | 大師 |
| 7 | 傳奇 |

稱號只是方便理解的文字標籤，不代表固定解鎖效果。

### 4.2 技能清單

| 分類 | 技能 |
|---|---|
| 戰鬥 | 近戰、遠程武器、格擋、閃避、戰術 |
| 探索 | 偵查、追蹤、潛行、攀爬 |
| 操作 | 開鎖、工程、製作、拆陷阱 |
| 知識 | 歷史、神秘學、醫療、自然知識 |
| 社交 | 交涉、洞察、欺瞞、威嚇、領導 |
| 生存 | 生存、急救、環境適應、意志抵抗 |
| 特殊 | 儀式、通靈、防護 |

「生存」由原本的「求生」與「野外生存」合併而成。「防護」「意志抵抗」已正式加入；它們放在哪個分類是原型的暫定安排，可以再調整。
