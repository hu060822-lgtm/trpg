# 參考 Roll20／Foundry VTT 的改進方向

> 2026-10-27 依 luz 的建議整理。Roll20 與 Foundry VTT 是同步跑團工具（大家同時在線），FATEWEAVE 是非同步、伺服器裁決的持續世界，所以只借用適合的部分。

| VTT 功能 | 在 Roll20／Foundry 的樣子 | FATEWEAVE 的對應 | 狀態 |
|---|---|---|---|
| 先攻／回合追蹤器 | 依先攻排序、標出目前行動者、輪數 | 戰鬥沙盒的回合時間軸 | ✅ 已做 |
| 代幣血條與狀態標記 | 代幣上的 HP 條、中毒／倒地圖示 | 戰場代幣的 HP 條、狀態文字、瀕死判定圓點 | ✅ 已做 |
| 擲骰卡片 | 聊天室裡顯示公式、骰面、結果 | 判定紀錄卡片：骰面、總值、差距、結果分級、判定 ID | ✅ 已做 |
| 密骰／GM 暗骰 | `/w gm`、`/gmroll`、blind roll | 擲骰可選「公開／密骰給 GM／GM 暗骰」，可切換玩家或 GM 視角檢視；暗骰時玩家看不到骰值與難度（符合企畫書 11.4 隱藏難度） | ✅ 這次新增 |
| 巨集列 | 一鍵擲常用檢定 | 依職業核心屬性與技能產生的快速擲骰按鈕 | ✅ 這次新增 |
| 3D 擲骰動畫 | Dice So Nice | 瀕死骰的翻滾動畫 | ✅ 已做（之後可推廣到所有擲骰） |
| 圖層與 GM 圖層 | 只有 GM 看得到的物件 | 世界檢視依身分過濾：GM 備註、隱藏物品、別人背包 | ✅ 已做（伺服器端過濾） |
| 日誌與講義權限 | 可設定給誰看的 Journal／Handout | 世界歷史的可見性（公開／場景／私人／GM） | ✅ 已做；GM 手動發「講義」給指定玩家可在 Phase 5 做 |
| 戰爭迷霧／動態光源 | 只顯示角色看得到的地圖區域 | 地點層級的可見性已做；格子地圖與視線可在正式前端（React）時評估 | 之後 |
| 角色卡點擊擲骰 | 在角色卡上點技能直接擲 | 巨集列是第一步；正式角色頁每個技能旁放擲骰按鈕 | 之後 |
| 主動效果 | Foundry Active Effects：狀態自動修改擲骰 | 重傷自動劣勢已做；之後把 buff／debuff 做成有持續時間的效果資料 | 之後 |
| 範圍模板 | 錐形、半徑量測 | 目前戰鬥用 4 段距離帶，不需要 | 不做 |
| 合輯 | 規則、物品、怪物資料庫 | `config/` 已經是資料檔；之後可做成可搜尋的規則書頁面 | 之後 |
| 非同步通知 | （VTT 沒有） | 每回合期限、逾時預設行為、Discord 通知 | Phase 5 |

## 不直接照搬的部分

- **同步聊天室**：FATEWEAVE 的行動是非同步提交、伺服器結算，不能讓聊天訊息直接改變狀態。紀錄卡片只呈現已經結算的結果。
- **GM 自由修改骰值**：VTT 允許 GM 改任何數字；FATEWEAVE 的骰值由伺服器產生並保存，GM 能做的是裁決（例如確認 PvP 死亡），所有裁決都留稽核紀錄。
